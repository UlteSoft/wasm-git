# Native binary formats

The current maintained format reference is available in
[English](../documents/BINARY_FORMAT.eu_US.md) and
[简体中文](../documents/BINARY_FORMAT.zh_CN.md).

It describes the current `WGTPACK4` layout, canonical objects and manifests,
author signatures, shallow/promised state, binary control files, byte patches,
and negotiated RPC transfer. Superseded pre-release layouts are not migration
contracts. JSON remains an external reporting/configuration-import interface.
