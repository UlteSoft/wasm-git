# 本地 Web 界面与服务器监管手册

[English](WEBGUI.eu_US.md) · [文档库](README.zh_CN.md)

## 架构与环境要求

`webgui/client.py` 和 `webgui/server.py` 是两个独立的 Python 3.10+ 启动入口，
共用标准库 HTTP 桥接层和静态页面。它们通过参数数组调用现有原生 `wasm-git`
和 `wasm-git-server`，参数不经过 shell。Web 界面以源码分发，不编译进任何原生
程序，也不需要 pip、npm 或前端构建步骤。

客户端界面用于审阅与操作本地仓库；服务端界面包含客户端能力，并增加指定托管
根目录的监管功能。界面调用原生协议、存储、认证、作者验证、分支保护和接收事务，
这些功能仍由原生程序负责实现。

## 启动、程序查找与关闭

在源码根目录执行：

```sh
python3 webgui/client.py start --repo /absolute/repository --open
python3 webgui/server.py start --root /absolute/hosting-root --open
python3 webgui/client.py status
python3 webgui/server.py status
python3 webgui/client.py stop
python3 webgui/server.py stop
```

默认端口分别是 8737 和 8738。使用 `--port` 修改端口后，查询状态和关闭时也应
传入相同端口。`--state-dir` 默认是源码目录下的 `.tmp/webgui/`，生命周期命令
需要使用相同目录。`serve` 在前台运行，可用 Ctrl-C 关闭。不传 `--repo` 时，
可以在浏览器中创建、克隆或选择仓库；原生仓库包含 `.wasm-git/` 目录。

程序查找顺序为：显式 `--client` / `--server` 参数、相应的 `WASM_GIT_CLIENT`
/ `WASM_GIT_SERVER` 环境变量、PATH，以及本地 `target`、`.tmp/target`、
`.tmp/webgui-build` 下的 release/debug 目录。显式路径无效时会报错。没有找到
程序时，启动器使用 Cargo 将所需原生程序构建到 `.tmp/webgui-build/`。本机须已
安装 Cargo 和原生 C 工具链，依赖可能需要下载；启动器不会安装工具链。
`--no-build` 禁止自动构建；`--build` 强制从当前源码重新构建。
server 构建使用 `--no-default-features --features server --bin wasm-git-server`；
client 使用默认 client feature 和 `--bin wasm-git`。

启动后会打印带随机会话令牌片段的完整 URL。请打开完整地址；页面将令牌放入标签
页的 session storage，并从地址栏移除。`--open` 请求系统自动打开浏览器。
启动日志与紧凑二进制进程状态文件位于本地状态目录。

## 中英文切换与审计原文

右上角可选择 English 或简体中文，无需刷新页面。静态标签、动态操作表单、确认
对话框、命令分类、审计说明和服务器监管控件均参与切换。首次访问优先采用浏览器
首个受支持的语言，已有偏好则优先使用偏好；偏好按浏览器 origin 保存。禁用浏览器
存储时仍能切换当前页面。界面标识遵循项目的 `eu_US` / `zh_CN` 约定，HTML 语言
标签使用 `en-US` / `zh-CN`。

切换不会翻译可编辑值。提交说明、分支名、路径、符号、指令、偏移、原生 JSON
字段和下载输出始终保留原文。例如，提交标题是 `Overview` 时，中文界面仍显示
`Overview`。原生帮助和诊断保留程序输出的语言，界面自身的说明会本地化。
语言选择不会改变命令参数、仓库记录、匹配证据或字节还原结果。

## 仓库操作与审计

概览显示分支/HEAD、已跟踪文件、暂存改动、工作区改动及待处理操作。文件操作可
暂存、取消暂存、检查、比较、丢弃改动或选择冲突一方。提交说明支持多段文本。
历史视图显示父提交、签名、浅克隆边界及选中提交的文件树。仓库工具提供分支、
标签、远程、仅快进拉取、推送、stash、reset、合并/重放、GC 和完整性检查。
可能覆盖文件或改写历史的结构化操作会先展示具体选择，原生程序仍执行自身检查。

比较视图支持工作树与索引、索引与 HEAD、两个版本之间的差异，并可按文件或
section 筛选，例如 `code`、`custom:producers`。页面展示函数和指令改动，以及
精确的新旧字节范围；关联歧义、类型化分析不完整会明确显示。初始页面每个函数
显示至多 250 处指令编辑、每个文件至多 200 处字节编辑，点击「显示更多」可继续查看。
大段十六进制按 4 KiB 分批展开；完整原始报告也可经主动确认导出。
原始字节是审计证据，元数据与推断的源码对应关系仅供参考。

Wasm 浏览器可检查已提交模块或工作树文件。调试查询支持符号名、函数索引、文件
字节偏移、代码 payload 偏移、Go 虚拟 PC 和记录的源码路径。外部 source map 或
调试 Wasm 文件必须位于所选工作树内。Go PC 与文件偏移是不同的坐标。

## 完整命令入口

功能目录按历史、Wasm 审计、远程、存储、native/SSH/OpenPGP 签名、WasmHub PR、
底层索引/对象/引用分类提供命令表单。表单准备可编辑参数，不会自动执行。当前
选项以已安装程序的帮助为准；模板只是起点，需要替换为真实 ID 和路径。

命令工作台可使用所选程序识别的全部参数，包括此界面版本之后新增的参数。
每个参数使用独立输入框，不包含程序名；空值和嵌入换行均会保留。
工作目录必须存在。环境变量覆盖仅传给子进程，不写入任务元数据。子进程继承
已有 SSH agent 和原生凭据机制；需要终端输入的密码/PIN 认证应提前在本地准备。
桥接层提供管道，不提供伪终端。

标准输入可读取本地普通文件，或保持开启以处理交互式批量输入。文本和文件分块
发送，可显式发送 EOF。标准输出和标准错误分别保存为二进制文件；浏览器
默认只展示状态与输出大小，主动查看后可见 UTF-8 预览，下载保留 NUL 和非 UTF-8 等原始字节。可以重新选择本次会话中的任务、
下载输出或删除已完成输出。任务输出只在当前 GUI 会话中保留，关闭前请下载。

## 服务器监管

监管页扫描指定根目录下的非符号链接仓库，显示范围限制为八层目录、最多遍历
10,000 个目录和展示 1,000 个仓库。可调用原生完整性/存储命令，并读取接收审计
文件。回环 TCP 探测仅验证监听端口是否可连接，不代表协议健康或认证成功。
显式配置后原生服务可以监听其他地址，管理界面自身始终只监听回环地址。

启动表单覆盖 HTTP/stdio、访问模式、连接上限、令牌/策略文件、SSH 身份、强制
更新、信任作者、保护规则、合并身份/密钥/格式以及 receive/update 钩子。启动前
可以审阅根目录、传输方式、监听地址和访问模式；不展示完整启动参数。每个 GUI 实例可托管一个服务，同时执行客户端操作和独立的
服务端管理命令。停止控件仅影响该实例启动的进程，不接管已有外部服务。修改
策略或保护文件后需重启原生服务才能加载。

访问策略和保护规则的 JSON 输入经原生 server 编译为二进制文件；JSON 是面向
人的配置输入，不是仓库内部存储。审计查看器读取原生二进制记录，预览最新
100 条，并以去除已知凭据后的结构化字段呈现。PR 审阅、检查、合并和签名通过命令目录调用原生功能，
权限与预期 ID 检查由服务器执行。详见 [WasmHub 手册](WASMHUB.zh_CN.md)。

## 限制、失败处理与信任范围

HTTP 桥接层检查 Host、Origin、fetch-site 上下文和会话令牌，不开放 CORS 或任意
文件系统静态路由。CSP 禁止外部脚本和嵌入框架；仓库和原生输出以文本插入页面，
不会解释成 HTML。这是拥有启动用户文件权限的本地管理工具，不用于公网多用户托管。

预览查询最多同时运行两个进程，默认超时为 120 秒，标准输出上限为 32 MiB，
标准错误上限为 256 KiB。超限会明确报错，不展示截断审计。可缩小筛选范围、调整
`--timeout`，或使用命令工作台下载较大输出。同一实例内的结构化写入和客户端任务
串行执行；独立进程仍依赖原生仓库锁。命令任务没有固定运行时限，每个输出流默认
上限为 256 MiB，可用 `--job-output-mib` 调整；每类执行目标最多保留 64 个任务，
达到上限后需删除已完成输出。

原生退出码、标准错误、部分完成或冲突结果都会保留。取消、超时、输出超限或关闭
可能在写入部分完成后中断操作；重试前请检查状态、待处理操作和接收审计。
POSIX 使用独立进程组，Windows 使用原生进程树终止工具。关闭 GUI 会停止其命令
及托管服务并清理临时输出，不会撤销已经完成的仓库操作。

## 验证与命名

`webgui/test_webgui.py` 使用真实原生程序，通过 HTTP 验证令牌/来源拒绝、只读
预览、独立字节重建、暂存/历史、字面路径、二进制批量输入输出、取消/输出上限、
策略/保护编译、认证推送/审计及启动关闭。`webgui/test_catalog.cjs` 根据原生帮助
检查命令覆盖和双语占位符。CI 执行这些检查及 JavaScript 语法检查。生成的仓库、
报告、截图和进程状态都位于 `.tmp/`。

当前预发行版本统一使用 `.wasm-git`、`WASM_GIT_*`、`/v1/wasm-git` RPC 路由、
`WGT` 格式魔数前缀以及索引魔数 `WASMGIDX`。旧内部名称和签名不兼容，也不迁移。
请使用配套的新 client/server 构建和新初始化的原生仓库。

## 项目工作台、持久化与操作归属

入口提供「打开项目」「创建项目」「克隆项目」。支持浏览本地目录或手动输入路径，
创建和克隆需要父目录与项目名。已打开项目显示为卡片，并可通过左侧选择器切换。
关闭只将项目放入最近列表，移除最近记录也不会删除仓库。最多保留 100 个项目，
使用独立、权限受限的 SQLite 二进制数据库跨 GUI 会话持久化。

每次结构化查询和写入都携带项目 ID，后端通过注册表解析路径并拒绝已关闭或缺失项目。
切换项目会清空旧结果、参数、环境变量输入和原始流预览；旧项目的异步响应不会写入新视图。
提交草稿在页面内存中按项目隔离，刷新页面后不保留。关闭项目不会取消已提交的原生操作。
改动视图包括暂存／工作区文件分组、内联审计和提交面板；操作完成后会使旧预览失效。

## 人机接口与隐私边界

新版 GUI 调用[版本化二进制命令协议](COMMAND_PROTOCOL.zh_CN.md)，不解析终端摘要。
后端验证响应帧后筛选字段，页面使用卡片、表格和审计面板，不直接铺开原始 JSON。
默认 API 不返回完整 argv、环境变量、密钥／签名字节、编译来源和嵌入源码正文，
并去除已知凭据字段、掩码可识别的 URL 用户信息及认证／敏感赋值。这是后端过滤，不是 CSS 隐藏。
Wasm 原始指令、区间与字节证据仍保留原样；不能用静默脱敏破坏还原。

高级命令每个参数使用独立输入框，保留空值和换行；环境变量使用名称／掩码值表单，
启动后清空。命令执行后默认只显示状态、退出码和输出大小，不自动显示 stdout／stderr。
原始流和审计报告需要主动查看或导出；界面明确提示其中可能有路径、源码和敏感值。
下载保留 NUL、非 UTF-8 等原始字节。服务器卡片仅展示运行状态及控制入口，不展示完整启动参数。
接收审计以筛选后的结构化字段显示，正常页面不再提供裸 JSON 展开。

新增验证覆盖项目生命周期与持久化、跨项目操作隔离、JSON／二进制响应一致性、大小端
黄金样本、畸形帧拒绝、敏感字段过滤及主动导出。原有暂存、历史、策略、接收审计、
二进制对象流、取消和启动停止检查继续执行。

客户端界面克隆后会检出命名文件；如果检出失败，仍保留已克隆项目并显示恢复提示。
