# wasm-git Documentation

Read the complete documentation library in
[English (`eu_US`)](README.eu_US.md) or [简体中文 (`zh_CN`)](README.zh_CN.md).

Both editions include a technical white paper, user manual, server administration
manual, binary-format reference, and development and verification guide.
The documents describe current implementation contracts and explicit limits;
generated test reports and profiles are kept outside published source.

The local Web GUI manual is available in [English](WEBGUI.eu_US.md) and
[简体中文](WEBGUI.zh_CN.md), covering both client and server entry points.
