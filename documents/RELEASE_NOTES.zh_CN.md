# wasm-git 0.1.2 预发行版

新增 **uwvm2-ros VM 指令扩展** 中的 WasmMTE 类型化审计。统一外层为
`0xFF + ULEB32(完整指令编号) + 各指令自己的操作数`，不把版本／域位或 memory
index 强加给未来的其他扩展族。

- 19 条已登记 WasmMTE 指令完整保留 memory 立即数，支持 memory32/64、导入／共享
  memory、多字节索引与合法填充。add 保留；未知编号及旧编码不提供兼容解码，未知
  表达式后缀仍保留精确原始字节。
- 操作码和 memory 变化可在函数／基本块／指令级审计。新增
  uwvm.memtag.linear.globals v2 的 u32/u64 独立字段及 section 筛选；非该约定的
  custom 数据保持不透明、无损，不因约定不符拒绝文件。
- 补丁、历史及压缩 GC 精确保留原始字节，独立正反向还原与各平台发行测试验证。
- 各压缩包附带中英文扩展规范。
- 包括双语本地 Web GUI、创建／打开／克隆／切换项目、独立服务监管，以及显式
  文本／JSON／二进制输出协议，严格字节序校验与主动查看／导出原始输出。

发布前本机在 64 GiB、零 swap cgroup 中完成 600 秒、16 个 E-core 工作线程测试：310,633 轮合法模块更新、621,266 个合法模块验证、310,633 次畸形扰动及 1,242,532 次正反向序列化补丁还原，未发现失败。有限测试不等于对所有可能输入的证明。

发布须通过完整回归、Linux QEMU、Windows/macOS 原生及 WASIp1 MVP/Core2 执行。
原生包包括客户端和服务端，WASIp1 包为单线程客户端，保留已有外部进程／网络服务
能力限制。下载后校验 SHA256SUMS。

本项目使用 wasm-git 原生仓库和网络格式。预发行版不承诺兼容原生 Git 协议。
审计不执行 Wasm，也不认证 VM 内存安全。原始字节及主动导出可能包含私有应用内容，
二进制编码不等于加密。
